# Data notice

The files in this folder are generated by `scripts/build-ingredient-data.mjs` from the
[Open Food Facts](https://world.openfoodfacts.org) taxonomies (`food/ingredients.txt`, `additives.txt`,
`additives_classes.txt`, commit `f827fce90bf548c33d14ec79c55d803f6367867e`).

- `ingredient-names.json`: English ingredient names and synonyms
- `additives.json`: additive codes with their English name and functions
- `additive-names.json`: English additive names and synonyms mapped to codes
- `additive-classes.json`: additive function names

They are a derivative of the Open Food Facts database, made available under the
[Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/). These derived files are
offered under the same licence. © Open Food Facts contributors.

Don't edit them by hand: change the generator and run `npm run data:ingredients`.
